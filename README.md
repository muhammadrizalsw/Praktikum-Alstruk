# Praktikum Algoritma dan Struktur Data (Alstruk)

Repositori ini berisi kumpulan kode program Python yang dibuat untuk keperluan tugas dan materi Praktikum Algoritma dan Struktur Data.

---

## 📌 Daftar Isi File

Berikut adalah berkas-berkas program yang terdapat dalam repositori ini:

* `Looping.py` — Implementasi konsep perulangan (*looping*) dalam bahasa Python.
* `nilai mhs.py` — Program pengolahan data nilai mahasiswa (perhitungan, pengolahan data, atau evaluasi nilai).
* `praktikum 1.py` — Praktikum 1: Dasar Python (Variabel, Tipe Data).
* `praktikum 2.py` — Praktikum 2: Struktur Kontrol (Percabangan).
* `praktikum 3.py` — Praktikum 3: Perulangan (Looping).
* `praktikum 4.py` — Praktikum 4: Struktur Data List.
* `praktikum 5.py` — Praktikum 5: Struktur Data Dictionaries.
* `tantangan.py` — Latihan tantangan implementasi algoritma terapan.
